SECTION 01

프로젝트 개요 및 기획 의도

『내 약국에는 정상이 없다』는 단순 반복형 클릭커 타이쿤에서 벗어나, "손님의 기괴한 대사 속 숨겨진 증상 유추"와 "물리적 재료 배합 인터랙션"을 결합하여 플레이어에게 퍼즐 해결의 쾌감과 코믹한 내러티브 경험을 제공하고자 기획되었습니다.

💊 독창적인 블랙코미디 세계관

‘투명인간이 되고 싶은 손님’, ‘기억을 지우고 싶은 로봇’ 등 독특한 NPC 페르소나와 위트 있는 다이얼로그 시스템 구축.

⚗️ 모듈형 조합 메커니즘

기본 베이스 액체 4종과 특수 시약 12종의 화학 반응 및 상성 규칙을 ScriptableObject 데이터 기반으로 설계.

⚡ 직관적인 드래그 & 드롭 조작

스마트폰 및 PC 환경에서 마우스/터치로 약병을 흔들고 따르는 물리 기반 피드백 인터랙션 구현.

SECTION 03

약물 조제 및 검증 C# 시스템 아키텍처

수많은 재료의 투입 순서와 비율을 유연하게 판정하기 위해 해시 기반의 레시피 매칭 엔진(RecipeMatcher)을 설계했습니다.

// 재료 조합 검증 및 약품 완성 매니저 public class BrewingStation : MonoBehaviour { [SerializeField] private RecipeDatabase recipeDb; private readonly List<IngredientID> currentIngredients = new(); public void AddIngredient(IngredientID ingredient) { currentIngredients.Add(ingredient); AudioManager.Instance.PlaySfx(SfxType.LiquidPour); UpdateBeakerColor(); } public MedicineResult FinalizeBrew() { var matchedRecipe = recipeDb.FindMatchingRecipe(currentIngredients); if (matchedRecipe != null) { return new MedicineResult(matchedRecipe.ResultMedicine, Quality.Perfect); } return MedicineResult.FailedPotion(); // 실패 시 폭발 또는 독극물 반환 } }
SECTION 04

트러블슈팅 및 문제 해결

⚠️ 직면 문제: 복합 재료 조합 시 순환 참조 및 성능 저하

재료가 3개 이상 섞일 때마다 매 프레임 리스트 전체를 탐색하는 무차별 대입 방식(Brute Force)으로 인해 모바일 환경에서 프레임 드랍 발생.

💡 해결책: 재료 조합별 고유 비트마스크(Bitmask Hash) 키를 생성하여 O(1) 딕셔너리 룩업 방식으로 구조를 전면 리팩토링. 룩업 소요 시간을 94% 단축.

⚠️ 직면 문제: 씬 전환 시 조제 데이터 유실

약국 로비 씬과 지하실 조제실 씬 간 이동 시 진행 중이던 비커 상태가 리셋되는 현상.

💡 해결책: 싱글톤 기반의 GameSessionContext를 도입하여 씬 언로드 시에도 상태를 직렬화(JSON)하여 유지하도록 처리.
