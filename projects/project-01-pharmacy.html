SECTION 02 · GROWTH & COMPETENCY

경험 전후의 학습 성과 및 핵심 역량 평가

수행 전 (BEFORE: 직면한 한계)
  • 재료 개수가 늘어남에 따라 매 프레임 리스트를 순회하는 무차별 탐색(O(N))으로 인해 모바일 환경에서 프레임 드랍 발생
  • GameManager 단일 클래스가 UI, 씬 전환, 조제 판정까지 모두 제어하려는 거대 객체(God Object) 종속성 문제 직면
  • 기획자가 시약 수치를 바꿀 때마다 코드를 열어 상수를 수정해야 하는 번거로운 하드코딩 의존성 존재
수행 후 (AFTER: 달성한 학습 성과 & 역량 성장)
  • O(1) 비트마스크 해시 룩업 알고리즘 구축: 16종 시약 조합을 딕셔너리 키로 즉각 매칭하여 연산 소요 시간 94% 단축
  • 이벤트 기반 느슨한 결합(Decoupling) 체득: Action/Delegate 옵저버 패턴을 통해 GameManager를 오케스트레이터로 경량화
  • ScriptableObject 데이터 파이프라인 완성: 기획자가 인스펙터에서 즉시 시약 상성과 텍스트를 편집할 수 있는 확장 구조 확립

[협업 및 갈등 해결 사례]

조제 난이도와 연출 분량에 대한 기획 충돌: 초기 기획에서 "더 복잡한 미니게임(원심분리기, 가열 단계)"을 추가하자는 의견이 제시되었으나, 조작 피로도가 급상승하고 마감 기한이 위태로워졌습니다. 이에 "핵심 재미(손님의 대사 추론과 비커 믹싱)에 집중하자"는 MVP 기준을 데이터로 제시하고, 부가 기기는 2차 업데이트 마일스톤으로 분리 조율하여 일정 내 완성도 높은 코어 빌드를 성공적으로 마감했습니다.

SECTION 03

프로젝트 개요 및 기획 의도

『내 약국에는 정상이 없다』는 단순 반복형 클릭커 타이쿤에서 벗어나, "손님의 기괴한 대사 속 숨겨진 증상 유추"와 "물리적 재료 배합 인터랙션"을 결합하여 플레이어에게 퍼즐 해결의 쾌감과 코믹한 내러티브 경험을 제공하고자 기획되었습니다.

독창적인 블랙코미디 세계관

‘투명인간이 되고 싶은 손님’, ‘기억을 지우고 싶은 로봇’ 등 독특한 NPC 페르소나와 위트 있는 다이얼로그 시스템 구축.

모듈형 조합 메커니즘

기본 베이스 액체 4종과 특수 시약 12종의 화학 반응 및 상성 규칙을 ScriptableObject 데이터 기반으로 설계.

직관적인 드래그 & 드롭 조작

스마트폰 및 PC 환경에서 마우스/터치로 약병을 흔들고 따르는 물리 기반 피드백 인터랙션 구현.

SECTION 05

약물 조제 및 검증 C# 시스템 아키텍처

수많은 재료의 투입 순서와 비율을 유연하게 판정하기 위해 해시 기반의 레시피 매칭 엔진(RecipeMatcher)을 설계했습니다.

// 재료 조합 검증 및 약품 완성 매니저 public class BrewingStation : MonoBehaviour { [SerializeField] private RecipeDatabase recipeDb; private readonly List<IngredientID> currentIngredients = new(); public void AddIngredient(IngredientID ingredient) { currentIngredients.Add(ingredient); AudioManager.Instance.PlaySfx(SfxType.LiquidPour); UpdateBeakerColor(); } public MedicineResult FinalizeBrew() { var matchedRecipe = recipeDb.FindMatchingRecipe(currentIngredients); if (matchedRecipe != null) { return new MedicineResult(matchedRecipe.ResultMedicine, Quality.Perfect); } return MedicineResult.FailedPotion(); // 실패 시 폭발 또는 독극물 반환 } }
SECTION 06

트러블슈팅 및 기술적 문제 해결

[Issue] 복합 재료 조합 시 순환 참조 및 성능 저하

재료가 3개 이상 섞일 때마다 매 프레임 리스트 전체를 탐색하는 무차별 대입 방식(Brute Force)으로 인해 모바일 환경에서 프레임 드랍 발생.

[Solution] 재료 조합별 고유 비트마스크(Bitmask Hash) 키를 생성하여 O(1) 딕셔너리 룩업 방식으로 구조를 전면 리팩토링. 룩업 소요 시간을 94% 단축.

[Issue] 씬 전환 시 조제 데이터 유실

약국 로비 씬과 지하실 조제실 씬 간 이동 시 진행 중이던 비커 상태가 리셋되는 현상.

[Solution] 싱글톤 기반의 GameSessionContext를 도입하여 씬 언로드 시에도 상태를 직렬화(JSON)하여 유지하도록 처리.

최종 분석 결과 및 핵심 결론 (Key Takeaways)

『내 약국에는 정상이 없다』는 단순 타이쿤 규칙에 머무르지 않고, "대사 추론 기반의 심리 퍼즐"과 "O(1) 비트마스크 해시 조제 아키텍처"를 결합하여 모바일 환경에서도 안정적인 60fps와 높은 플레이 몰입감을 입증한 프로젝트입니다. ScriptableObject를 통한 기획 데이터 분리와 이벤트 위임 패턴을 통해 유지보수성과 확장성을 두루 갖춘 상용화 수준의 코어 루프를 완성했습니다.
