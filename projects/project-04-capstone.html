SECTION 02 · GROWTH & COMPETENCY

경험 전후의 학습 성과 및 핵심 역량 평가

수행 전 (BEFORE: 직면한 한계)
  • 플레이어 공격, 방어, 패링, 피격 상태가 하나의 거대한 if-else 스위치 문으로 얽혀 신규 애니메이션 추가 시 버그 폭증
  • 팀원들이 main 브랜치에 직접 푸시하면서 Unity 씬 파일(.unity) 충돌로 작업물이 유실되는 협업 리스크 발생
  • 공격 판정 타이밍이 프레임레이트에 종속되어 저사양 기기에서 판정 누락(히트스킵) 문제 발생
수행 후 (AFTER: 달성한 학습 성과 & 역량 성장)
  • IState 인터페이스 기반 모듈형 FSM 아키텍처 구축: 모든 행동을 독립된 클래스로 격리하여 사이드 이펙트 제로화
  • Git-Flow 및 LFS 브랜치 전략 도입: 씬 충돌을 예방하고 프리팹 단위 협업 워크플로를 확립하여 팀 생산성 2배 향상
  • 프레임 비종속적 히트박스 판정: FixedUpdate 및 물리 오버랩 연산과 히트스탑(Hitstop) 쉐이크 기법으로 타격감 완성

[협업 및 갈등 해결 사례]

씬 파일 덮어쓰기로 인한 팀원 간 감정적 마찰: 프로젝트 초기 레벨 디자이너와 프로그래머가 동일한 전투 씬을 동시에 수정하다가 대규모 머지 충돌이 발생해 반나절 분량의 작업이 소실되는 위기를 겪었습니다. 이에 시스템 개발자로서 즉시 Git-Flow 전략을 공식 수립하고, 씬 파일 자체를 직접 건드리지 않고 각 기능(플레이어, UI, 에너미 스포너)을 독립 프리팹(Prefab Stage)으로 격리 분업하는 규칙을 제안했습니다. 규칙 도입 이후 씬 충돌 0건을 달성하며 협업 신뢰도를 회복했습니다.

SECTION 03

프로젝트 개요 및 기획 의도

본 캡스톤 프로젝트는 "명확한 피격 판정과 반응성 높은 3D 액션 전투 루프"를 목표로 기획되었습니다. 스파게티 코드가 되기 쉬운 적 AI와 플레이어 전투 로직을 인터페이스 기반으로 철저히 분리하여 유지보수성을 극대화했습니다.

반응형 액션 전투 루프

공격 선딜레이, 히트스탑(Hitstop), 넉백, 그리고 정확한 패링 타이밍 판정을 프레임 단위로 제어.

계층적 적 AI FSM

순찰(Patrol) → 의심(Suspicious) → 추적(Chase) → 스킬 콤보(Combo Attack) → 그로기(Groggy) 상태 전이 구조화.

데이터 주도 설계 (Data-Driven)

모든 공격 판정 반경, 데미지 계수, 쿨다운 수치를 ScriptableObject 에셋으로 분리하여 기획적 밸런싱 편의 제공.

3D ACTION SYSTEM · FSM AI 시야각 및 타격 판정 기즈모 뷰 UNITY SCENE VIEW & WEBGL PROTOTYPE
캡스톤 디자인 인게임 전투 및 AI 기즈모 시연 슬롯

3D 환경에서 적 AI가 플레이어를 감지하고 스킬 콤보를 전개하는 인게임 액션 녹화 GIF/스크린샷 및 WebGL 빌드 화면 배치 영역입니다.

에디터 상에서 적의 시야각 원뿔(Frustum)과 탐지 반경을 실시간으로 시각화하여 레벨 디자인 직관성 확보.

Cinemachine 임펄스 소스를 활용해 공격 적중 시 묵직한 카메라 쉐이크 및 파티클 이펙트 동기화.

SECTION 05

확장 가능한 FSM 상태 전이 아키텍처

모든 몬스터와 보스 객체가 공유하는 IState 인터페이스 및 상태 전이 제어기 코드입니다.

// 공통 유한 상태 머신 인터페이스 public interface IState { void OnEnter(); void OnUpdate(); void OnExit(); } // 보스 및 정예 몬스터 상태 머신 컨트롤러 public class BossStateMachine : MonoBehaviour { public IState CurrentState { get; private set; } private float stateTimer; public void TransitionTo(IState nextState) { if (CurrentState == nextState) return; CurrentState?.OnExit(); CurrentState = nextState; stateTimer = 0f; CurrentState.OnEnter(); } }

개발 마일스톤 및 기술적 추진 계획

최종 분석 결과 및 핵심 결론 (Key Takeaways)

『2026 캡스톤 디자인』은 대학 3년간 갈고닦은 C# 아키텍처 설계와 Git-Flow 협업 역량을 총집결한 마스터피스입니다. IState 인터페이스로 분리된 FSM 패턴을 통해 복잡한 액션 콤보를 안전하게 확장 가능하도록 구조화했으며, 체계적인 프리팹 분업으로 팀의 협업 안정성과 개발 속도를 극대화했습니다.
