누리살이

GameAify AI 기술상 수상작 · 플레이 루프와 생성형 AI 기술의 유기적 융합

전통적인 생활형 라이프 심(Life-Sim) 게임 루프와 생성형 AI 인터랙션을 결합하여 새로운 형태의 어드벤처를 선보인 프로젝트입니다. 플레이어의 선택과 날씨, 호감도 맥락에 따라 동적으로 반응하는 세계관을 설계하고, 이를 Unity 환경에서 구현하여 GameAify 게임 제작 공모전 AI 기술상을 수상했습니다.

개발 기간 2025.06 — 2025.09 (4개월)
수상 내역 GameAify 게임 제작 공모전 AI 기술상
사용 기술 Unity · GameAify API · C# UniTask · Clip Studio · GitHub
수행 형태 팀 프로젝트 (기획 & 클라이언트 리드 프로그래밍)
SECTION 02 · GROWTH & COMPETENCY

경험 전후의 학습 성과 및 핵심 역량 평가

수행 전 (BEFORE: 직면한 한계)
  • 단순 챗봇 형태의 LLM 호출만 염두에 두어, 인게임 상태(호감도, 날씨)가 AI 대화에 반영되지 못하는 겉도는 연동 한계
  • 외부 API 네트워크 응답 지연(1~2초) 시 클라이언트 프레임 정지 및 플레이 단절 문제 발생
  • AI가 짠 비효율적인 코드(매 프레임 GC 생성)를 검증 없이 수용할 뻔한 기술 부채 위험
수행 후 (AFTER: 달성한 학습 성과 & 역량 성장)
  • 구조화된 인게임 컨텍스트 JSON 래퍼 구축: 호감도/날씨/과거 사건을 AI 프롬프트에 자동 직렬화하여 살아있는 NPC 구현
  • UniTask 비동기 파이프라인 & 심리적 지연 은닉: 딜레이 구간에 NPC 고민 모션/감탄사 선재생으로 대기 불쾌감 제로화
  • AI 코드 검증 및 지식 부채 축소 집요함: AI 추천 코드를 무비판적으로 쓰지 않고 프로파일링하여 메모리 풀링으로 직접 개선

[협업 및 갈등 해결 사례]

제출 마감 3일을 앞둔 기획 추가 욕심 갈등: 팀원 중 한 명이 "시간대별 마을 조명 셰이더와 미니게임 3종을 반드시 더 넣어야 완성작 같다"고 강력히 주장하며 빌드 일정이 위기에 봉착했습니다. 이에 리드 개발자로서 "이번 공모전의 심사 기준은 AI 기술 융합의 완성도"임을 상기시키고, AI 대화 안정성 및 코어 루프를 MVP 필수 과제로 확정하고 그래픽 디테일은 차기 버전으로 분리했습니다. 결과적으로 무결점 빌드를 제출하여 AI 기술상 수상을 달성했습니다.

SECTION 03

프로젝트 개요 및 기획 의도

『누리살이』는 단순한 텍스트 챗봇 형태의 AI 연동을 지양하고, 인게임 캐릭터의 행동, 감정, 날씨 및 경제 시스템과 AI 응답이 상호작용하도록 설계되었습니다.

살아있는 마을 생태계

마을 주민 NPC들이 각자의 성격과 일과 루틴을 가지며, 플레이어의 평판에 따라 태도와 대사 톤이 유기적으로 변화.

AI 기술상 선정 배경

단순 LLM API 호출에 그치지 않고, 인게임 파라미터(친밀도, 소지품, 과거 대화 히스토리)를 구조화된 JSON 프롬프트로 가공해 전달하는 아키텍처로 높은 기술 평가 획득.

완결성 높은 게임 루프

채집, 농경, 거래, 대화로 이어지는 클래식 라이프 심(Life-Sim)의 규칙 위에 AI 이벤트를 서포팅 레이어로 안정적 결합.

SECTION 05

AI 프롬프트 파이프라인 및 Unity C# 통신

Unity 클라이언트에서 인게임 콘텍스트를 수집하여 비동기 HTTP 요청으로 안전하게 처리하고 인게임 이벤트로 디스패치하는 매니저 구조입니다.

// 인게임 맥락 정보를 포함한 AI 대화 요청 처리기 public class AiDialogueManager : MonoBehaviour { public async UniTask<string> SendNpcInteractionAsync(NpcEntity npc, string playerSpeech) { var payload = new AiPromptPayload { NpcPersona = npc.Data.PersonaPrompt, AffectionLevel = npc.Affection, CurrentWeather = WorldManager.Instance.CurrentWeather, PlayerInput = playerSpeech }; string json = JsonUtility.ToJson(payload); var response = await ApiClient.PostAsync("/api/gameaify/dialogue", json); return response.ParsedSpeech; } }
SECTION 06

트러블슈팅 및 네트워크 레이턴시 극복

[Issue] 외부 AI API 호출 시 1~2초간의 반응 레이턴시 체감

네트워크 환경에 따라 응답 대기 시간 동안 게임이 멈춘 것처럼 느껴져 플레이 흐름이 끊기는 문제 발생.

[Solution] NPC가 ‘고민하는 모션(Thinking Animation)’과 말풍선 타이핑 인디케이터(⋯)를 즉시 표출하고, 지연 시 사전 정의된 감탄사 오디오를 먼저 재생하여 심리적 대기 시간을 제로화.

[Issue] AI 반환값 파싱 에러에 따른 씬 크래시 위험

LLM 모델이 지정된 JSON 규격을 벗어난 이상한 특수문자나 빈 문자열을 반환했을 때의 예외 처리 미비.

[Solution] Regex 기반 JSON 무결성 검증 레이어를 두고, 파싱 실패 시 NPC의 사전 정의 기본 대사로 부드럽게 Fallback 처리하는 안전장치 구축.

최종 분석 결과 및 핵심 결론 (Key Takeaways)

『누리살이』는 신기술(AI)을 도입할 때 "기술 자체가 목적이 아니라, 플레이어에게 어떤 몰입과 선택의 즐거움을 주는가"를 증명한 프로젝트입니다. 단순 API 호출을 넘어 인게임 데이터와 AI 응답을 유기적으로 결합하는 구조화된 프롬프트 파이프라인을 구축하여 GameAify AI 공모전 기술상이라는 공인된 평가 성과를 도출했습니다.
