## 0. 프로젝트 핵심 브리핑 & 개발자 회고

- **장르**: PC 웹 기반 1인칭 촉각 대리운전 시뮬레이터 (생활 밀착형 멀티태스킹 주행·주차 시뮬레이션)
- **목적**: 오픈월드·AI 트래픽·전동 킥보드 루프를 붙이기 전에, 운전석 1평의 촉각 조작만으로 독립적인 재미가 성립하는지 Waterfall 최소 프로토타입으로 우선 검증하고 본편(Agile) 확장의 기준선을 확립함.
- **왜 이 게임을 만들어야만 하는가?**: 기존 레이싱/주행 게임이 다루지 않는 **"남의 차에 타자마자 엉망인 시트·미러를 급하게 맞추고, 한 번에 하나의 손 작업(단일 마우스 포인터)만 쓰며 `Q`/`E`로 사각지대를 빼꼼 살피는 한국형 대리운전의 긴장감과 촉각 손맛"**이라는 고유한 재미 포지션을 검증할 가치가 있음.
- **주요 기능과 핵심 구현**: `Vite + TypeScript + Three.js` 3D 콕핏, WebGL `RenderTarget` 실시간 거울 3종(우측 볼록 광각), 1:1 동기화 2D·3D 다회전 핸들(`±540°`), `W`/`S`/`Space` 분리 페달 HUD, `Q`/`E` 고개 회전·시트 높이·`1/2/3`+`WASD` 전동 미러, 경사 램프 `M`단 엔진 브레이크·과열 시뮬레이션, 차주 프리셋 4종.
- **진행하면서 어려웠던 점**:
  1. 초기 콕핏에서 3D 기어봉이 시야에 가려지고 감긴 핸들 각도 인지가 어려웠던 문제 → 3D 기어봉 전방 재배치, 우하단 콘솔, 좌하단 2D 핸들·페달 HUD, `FOV 76°` 및 상단 중앙 룸미러 재배치로 해결.
  2. 아날로그 마우스 드래그 기반 거울 조절의 높은 피로도 → `1/2/3`·`Z/X` 선택 + `WASD` 전동 모터 조절로 전환.
  3. 1인 개발 스코프 비대화 위험 → `Out of Scope` 6종 문서 잠금.
- **콘텐츠 개발하면서 깨달은 점**:
  1. **GDD 선행 정리 → Waterfall 프로토타입 → Agile 확장 규율**: 구현 전에 `01_concept.md`와 `02_prototype_plan.md`로 코어 루프와 제외 범위를 먼저 잠그고, Waterfall 단계에서는 운전석 손맛 검증(`Playtest Gate`)에만 집중한 뒤 Agile 단계로 넘어가기로 설계해 Feature Creep 없이 명확한 판단 기준을 유지할 수 있었음.
  2. **직관적인 즉각 피드백과 새로운 WebGL 기능의 빠른 실험**: `Vite + TypeScript + Three.js` 환경에서 `RenderTarget` 다중 미러링, `Raycaster` 3D 콕핏 인터랙션, 2D DOM HUD와 3D 물리 상태의 1:1 동기화 같은 새로운 웹 3D 기능을 무거운 빌드 대기 없이 코드 수정 즉시 화면에서 검증하며 빠르게 개선 사이클을 돌릴 수 있었음.

## 1. One-Page GDD

### 1.1 High Concept `[확정]`
> **"매 판 남의 차에 올라타, 틀어진 시트·거울을 급하게 맞추고 마우스로 핸들을 돌려 바쁜 밤 도로와 극악의 주차를 뚫어내는 1인칭 촉각 대리운전 시뮬레이터"**

접이식 전동 킥보드를 타고 야간 번화가 골목을 누벼 콜을 잡은 뒤, 킥보드를 접어 손님 차량 트렁크에 싣고 목적지까지 운전·주차까지 완수하는 PC 웹 기반 1인칭 주행 게임이다. 속도나 드리프트 대신 **"실제 운전석에 앉아 있는 촉각적 몰입감과 멀티태스킹 긴장감"**에 집중한다.

### 1.2 Target Player Fantasy `[확정]`
- 실제 자동차 운전석에서 핸들에서 잠깐 손을 떼고 기어·사이드미러·룸미러·시트를 만지작거리는 손맛과 긴장감
- 좁은 한국식 골목/빌라촌 주차장에서 사이드미러를 아래로 꺾어 뒷바퀴·연석을 보며 긁지 않고 주차해내는 성취감
- 피크타임 밤거리를 전동 킥보드 + 남의 차로 오가며 프로 대리 기사처럼 콜을 쳐내는 생활 밀착형 긴박감

### 1.3 Core Loop (`[확정]` / `[제안]`)
1. **콜 수락 & 전동 킥보드 접근 `[확정]`**: 앱에 뜬 고단가 콜을 수락하고 번화가 인도·이면도로를 전동 킥보드로 달려 차주 위치까지 이동
2. **킥보드 접기 & 트렁크 적재 `[확정]` / `[제안]`**: 킥보드를 접어 손님 차량 트렁크에 적재 *(트렁크 기존 짐 사이 적재 인터랙션 검토)*
3. **운전석 초기 세팅 `[확정]`**: 매 판 전 주인의 엉망인 세팅(바닥에 붙은 시트, 접히거나 하늘을 보는 사이드미러, 틀어진 룸미러, `P`/`N` 기어)을 출발 전 맞출지, 주행 중 한 손으로 맞출지 판단
4. **야간 혼잡 도로 주행 `[확정]`**: 바쁜 밤 도로 트래픽 속에서 `Q`/`E` 사각지대 확인, 마우스 핸들 다회전, `D`/`M` 변속 전환 병행 *(룸미러 뒷좌석 손님 감시 `[제안]`)*
5. **극한 주차 & 킥보드 회수 `[확정]`**: 좁은 주차 구역에서 사이드미러를 아래로 꺾어 연석·뒷바퀴를 확인하며 무사고 주차 → 기어 `P` + `Space` 체결 → 트렁크에서 킥보드 회수

### 1.4 MDA Breakdown
- **Mechanics (규칙/입력)**: 마우스 원형 드래그 다회전 핸들 + 속도 종속 복원력, 한 번에 하나의 손 작업만 가능한 단일 포인터 구조, 분리형 페달(`W`/`S`/`Space`)과 `P-R-N-D-M` 기어, `Q`/`E` 독립 고개 회전, 시트 높이별 시야 변화, 실시간 WebGL `RenderTarget` 거울 3종(우측 볼록 광각), 차주별 초기 세팅 오프셋
- **Dynamics (창발적 행동)**: 직선 주행 중 핸들에서 손을 떼 기어/거울을 만지다 차선 이탈 위기를 맞는 멀티태스킹, 출발 전 세팅 vs 시간 압박 트레이드오프, 감긴 핸들 각도 확인을 위한 `Q` 빼꼼/사이드미러 하향 조절, `R`/`D` 착각이나 `M` 변속 누락으로 인한 현실적 실수
- **Aesthetics (목표 감정)**: 촉각적 손맛(Sensation/Kinesthetics), 생활 밀착형 긴장감과 웃음(Challenge/Comedy), 시야 제약을 뚫은 정밀 주차 달성감(Mastery)

## 2. 1인 개발 스코프 분리 전략 & Waterfall 최소 스펙

### 2.1 핵심 재미 가설 (Waterfall Validation Hypothesis) `[가설]`
> "복잡한 오픈월드 도시나 AI 트래픽, 킥보드 루프가 아직 없더라도, `남의 차마다 틀어진 시트/미러 세팅 + 마우스 원형 핸들 회전 + W/S 분리 페달 + Q/E 고개 돌리기 + 경사 램프 M단 변속`만으로 좁은 장애물/주차 코스를 통과하는 것 자체가 땀 나고 재밌는 손맛을 만들어내는가?"

### 2.2 본편 확장 1인 개발 병목 제어 전략 `[제안]`
1. **쉐이딩 & 아트**: 야간 + Fog로 원거리 디테일을 실루엣 처리하고, 로우폴리 + 플랫/툰 쉐이딩 + Bloom + 발광 창문(Emission)·소수 네온 간판으로 라이팅 비용을 절감하며 **차량 내부 콕핏·미러 반사 품질**에 최우선 투자한다.
2. **맵 & 건물**: 통짜 오픈월드 대신 `500m × 500m` 내외 순환형 한국형 동네 1개(번화가 대로·먹자골목·빌라촌)와 1층 상가·중간층 창문·옥상 모듈의 랜덤 층수 조합으로 제작한다.
3. **도로 트래픽 AI**: 차선별 웨이포인트 레일 + 전방 Raycast 1~2개로 경량 주행하고, 플레이어와 충돌한 순간에만 Rigidbody 물리로 지연 전환하며, 반경 150~200m 밖 차량은 풀링·재스폰한다.

### 2.3 Waterfall 1차 프로토타입 최소 스펙 `[확정]` & Out of Scope
- **기술 스택**: `Vite + TypeScript + Three.js` (`games/project-dd/prototype/`)
- **무대**: 야간 테스트 주차장 & 좁은 골목 장애물 코스 + 경사 램프 1곳(오르막 `M` 1단 토크/`Space` 밀림 방지 vs 내리막 `D` 브레이크 과열·페이드 vs `M` 저단 엔진 브레이크)
- **초기 세팅 프리셋**: `190cm 거인 차주`, `155cm 단신 차주`, `좁은 골목 접힌 차주`, `랜덤 진상 차주`
- **Out of Scope (1차 제외 6항목)**: ① 500m 도시 맵/모듈 건물, ② 웨이포인트 AI 트래픽/신호등, ③ 전동 킥보드 주행 및 트렁크 적재, ④ 콜 앱·요금 정산·장비 업그레이드, ⑤ 뒷좌석 취객 NPC·멀미 게이지, ⑥ 다수 차량·사운드 폴리싱·계정/세이브 서버

## 3. 조작계 설계 사양 (`[확정]`)

- **2D 동기화 핸들 UI + 3D 핸들 림 (`좌클릭 홀드 + 원 그리기`)**: `±540°` 다회전, 주행 중 속도 비례 복원 / 정차 중 바퀴 마찰로 미복원
- **분리 페달 & 보조 (`W`/`S`/`Space`, `A`/`D`)**: `W` 액셀, `S` 브레이크(후진 안 됨), `Space` 사이드 브레이크, 좌하단 실시간 페달 시각화, `A`/`D` 깜빡이
- **시선 분리 (`Q`/`E`) & 시트 높이 (`[`/`]` · 우하단 버튼)**: A필러 사각지대·앞바퀴 조향 각도 빼꼼 확인, 시트 높이에 따른 앞 범퍼·대시보드·룸미러 시야 변화
- **전동 미러 조절 (`1/2/3`·`Z/X`·버튼 + `WASD`/십자패드, `F` 접기)**: 좌측 사이드·우측 볼록 광각·중앙 상단 룸미러 실시간 `RenderTarget` 렌더링
- **기어(`P-R-N-D-M`) & 경사 램프 `M`단 엔진 브레이크**: 우하단 콘솔 또는 3D 기어봉 조작, `M` 모드 시 `마우스 휠` 또는 `Shift`/`Ctrl`로 1~6단 직접 변속

## 4. 1~2차 UI·조작 개선 로그 & Playtest Gate Checklist

### 4.1 개선 로그 (`03_devlog.md` 및 프로토타입 반영 이력)
1. **Phase 0 (2026-11-26)**: 2026-11-19 아이디어를 `01_concept.md`, `02_prototype_plan.md`, `03_devlog.md`로 복원하고 `Vite + TypeScript + Three.js` Waterfall 1차 프로토타입 구현.
2. **1차 개선**: 운전석 시야에 가려지던 3D 기어봉을 전방 시야로 재배치하고, 우하단 콕핏 콘솔 UI(`P-R-N-D-M`, 사이드, 시트 높이, 미러 선택) 추가.
3. **2차 개선**: 3D 핸들과 동기화되는 좌하단 2D 핸들 UI 및 `S` 브레이크/`W` 액셀 페달 시각화 추가, 운전자 시점 거리·시야각(`FOV 76°`) 현실화 및 룸미러 상단 중앙 배치, 거울 조절을 아날로그 마우스 드래그에서 **`1/2/3`·`Z/X`·버튼 선택 + `WASD`(십자패드) 디지털 전동 조절**로 변경.

### 4.2 Playtest Gate Checklist (Waterfall → Agile 전환 기준 6문항 · 현재 검증 대기)
1. **[마우스 핸들 손맛]** 마우스로 핸들을 감았다 놓을 때(주행 복원/정차 미복원), 커서 이탈 스트레스보다 운전 손맛이 더 큰가? (`YES / NO`)
2. **[핸들에서 손 떼기 긴장감]** 기어나 거울을 만지기 위해 핸들에서 마우스를 떼는 구조가 재밌는 멀티태스킹 긴장감을 주는가? (`YES / NO`)
3. **[시트 & 거울의 실용성]** 시트 높이 및 미러 각도 조절이 사각지대·연석·주차선 확인을 위해 실용적이고 재밌게 작동하는가? (`YES / NO`)
4. **[`Q`/`E` 고개 돌리기]** `Q`/`E`로 고개를 돌려 사각지대·앞바퀴를 빼꼼 확인하는 동작이 자연스럽고 시야 문제를 해결하는가? (`YES / NO`)
5. **[기어·수동 `M`·경사 램프]** `S` 브레이크 / `R` 후진 구분과 경사 램프에서의 `M` 저단(엔진 브레이크/토크)·`Space` 밀림 방지 감각이 현실적이고 재밌는가? (`YES / NO`)
6. **[확장 가치 판단]** 이 코어 조작 위에 바쁜 밤 도로 트래픽과 전동 킥보드·대리운전 루프를 얹으면 계속 플레이하고 싶은 게임이 될 것 같은가? (`YES / NO`)
