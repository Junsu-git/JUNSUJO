# [Assignment 07] 소드 x 스태프 — 순위 상승 원인과 핵심 재미 분석

## 1. 순위 상승 결론과 핵심 재미

**최종 마감: 2026-11-19.** 약 30분간의 초반 플레이(전사 Lv.12 · 전투력 8.38k)와 11/12 조사 자료를 기준으로 정리한 분석입니다. 추가 심층 플레이 없이 초반 체험 범위로 마무리한 **별도의 심층 플레이·후속 추적은 진행하지 않는 최종본**입니다.

**순위 상승 결론: '국내 정식 출시 초기의 상승 흐름에 화산귀환 콜라보가 추가 동력으로 작용했습니다.'** 정식 출시일(`11/04`)과 콜라보 개시일(`11/11`) 이전에 이미 App Store 11위(`11/08`)까지 올라선 기록이 확인되므로, 기존 장기 서비스 게임의 역주행이 아니라 출시 초기 성장과 콜라보 시너지의 결합으로 해석해야 합니다. 신규 서버 증설이 순위 상승을 이끌었다는 근거는 확인하지 못했습니다. ([공식 출시 공지](https://swordxstaffkr.boltray.com/news/232), [공식 콜라보 예고](https://swordxstaffkr.boltray.com/news/225))

**플레이 핵심 강점: '조작 부담은 낮추고, 모험과 전투의 움직임은 살린 설계'입니다.** 퀘스트 목표 하이라이트, 타일 기반 이동, 다대일 전투, 원거리 적의 거리 조절, 스킬 사용 시 자동 위치 이동이 자연스럽게 맞물렸습니다. (초반 30분 체험에 기반한 분석이며 장기 잔존율·매출 전환 수치와는 별개입니다.)

## 4. 코어 루프 및 메커닉스 분석

### 4.1 초반 코어 루프

**퀘스트 목적 확인 → 타일 필드 이동·탐험 → 다대일 적 조우 및 전투 → 성장·저택 확인 → 다음 지역·전직 기대감.** 조작이 복잡하지 않으면서도 다음 목표가 뚜렷해 초반 30분 몰입이 끊기지 않았습니다.

### 4.2 커스터마이징 — 적은 조작으로 완성도 확보

다양한 헤어와 머리색·귀색 연동 옵션 덕분에 **짧은 시간 안에 개성 있는 외형을 완성**할 수 있습니다. 색상 조합을 일일이 맞출 피로를 덜어 초반 캐릭터 애착 형성으로 바로 이어집니다.

### 4.3 이동과 안내 — 편의를 주되 모험 감각 보존

목적지만 또렷하게 하이라이트하는 퀘스트 안내는 길을 헤매는 스트레스를 줄이면서도 **유저가 직접 타일을 밟고 탐험하는 감각**을 살려 줍니다. 또한 타일 단위로 구획된 이동 방식과 탑뷰 시점 덕분에 작은 모바일 화면에서도 나와 적, 목적지의 거리 관계를 한눈에 읽을 수 있었습니다.

### 4.4 전투 및 일자 베기 — 공간 변화가 주는 보는 재미

원거리 적은 접근 시 뒤로 물러나 거리를 벌리고, 근접 적은 속도·기믹에 따라 다가와 다대일 전투에서도 전장이 입체적으로 움직입니다. 특히 **일자 베기** 사용 시 캐릭터가 유효 위치로 이동한 뒤 직선 베기를 시전해, 유저의 위치 정렬 부담을 줄이고 스킬 효과를 선명하게 보여줬습니다.

*(필드 이동과 전투가 자연스럽게 이어져 '가디언 테일즈'나 오픈월드 모험과 유사한 흐름이 느껴졌으나, 이는 초기 경험 기준의 체감 비교입니다.)*

| 일자 베기가 핵심 위치로 이동해 발동함 | 정렬 조작을 보완해 스킬 효용 전달 | 4.4 스킬 |
| 저택 업그레이드와 타 클래스가 기대됨 | 전투력 외 공간 발전 및 플레이 스타일 확장 동기 | 7장 성장 |

초반 30분 체험에서는 치명적인 버그나 불편 UX가 발견되지 않았으며, 향후 기능별 검증을 위해 아래 QA 체크리스트를 별도로 설계했습니다.

## 6. 개발자 관점: 타일 전투와 QA 체크포인트

타일 이동·전투 구조에서는 **목표 선택, 위치 이동, 공격 판정, UI 표시가 서로 어긋나지 않는가**가 핵심 품질 요소입니다. 아래 표는 실제 발견한 결함이 아니라 구현 검증 시나리오입니다.

| 검증 대상 | 테스트 조건 | 확인해야 할 기대 동작 |
| --- | --- | --- |
| 일자 베기 이동 및 범위 | 적 일렬·분산 배치 후 스킬 반복 | 이동 목적지 이해 가능, 실제 타격 범위와 UI 표시 일치 |
| 이동 후보 칸 충돌 | 이동 목표 타일에 장애물·유닛 존재 | 진입 불가 칸 끼임·유닛 겹침 없이 안전한 대체 판정 작동 |
| 이동 중 타깃 소멸 | 이동 직전 다른 공격으로 적 사망 | 헛스윙·프리징 없이 표적 재선정 또는 자원 환불 일치 |
| 원거리 적 거리 벌리기 | 필드 구석·막다른 지형에서 접근 | 무한 왕복·정지 현상 없이 공격 모드 전환 처리 |
| 퀘스트 하이라이트 갱신 | 목표 완료 직후 다음 단계 진입 | 이전 강조 해제 및 다음 수행 가능 목적지 즉시 갱신 |
| 커마 색상 연동 저장 | 머리색·귀색 변경 후 재접속·장비 변경 | 연동 색상 데이터 유실 없이 실제 인게임 반영 |

*(초반 30분 기준 FPS·발열·네트워크 재접속 정량 측정은 수행하지 않았으므로 성능 평가는 보류합니다.)*

## 7. 기획자 관점: 편의성과 성장 동기의 배분

### 7.1 주도성과 편의성의 균형

탐험의 방향 선택은 플레이어에게 맡기고, 직선 스킬 위치 정렬처럼 번거로운 미세 조작만 시스템이 보조하는 설계가 인상적입니다. 조작 난도는 낮추면서도 '내가 직접 모험한다'는 체감을 지키는 적절한 타협점입니다.

### 7.2 다층 성장 목표와 BM 확인 범위

저택 업그레이드는 수치 외의 **공간 성장 재미**를, 스토어에 예고된 타 클래스(현자·주술사·투사·기사)는 **전투 방식의 확장**을 기대하게 만듭니다. 다만 전사 1개 클래스의 30분 초반만 체험했으므로 중후반 성장 정체(Paywall)와 App Store 월간권(7,500원)·뽑기 천장 효율은 검증 대상에서 제외했습니다.

### 7.3 현황 기반 SWOT 요약

| 구분 | 분석 요약 |

| **약점 · 한계** | 30분 초반 체험만으로 중후반 반복 전투 깊이·과금 압박도 검증 불가 |
| **기회** | 화산귀환 외형·검법·하우징 콘텐츠를 초반 호감 요소와 직접 연결 가능 |
