# 사이트 개편 작업 계획서 및 마크다운 링킹 가이드

> **문서 목적**: 포트폴리오 웹사이트(`JUNSUJO`)의 코드 변경을 진행하기 전, 팩트체크된 마크다운 문서들(`docs/portfolio_md/*.md`)을 기준으로 사이트 구조를 어떻게 개편할 것인지에 대한 전체 설계 및 상호 링킹 가이드라인입니다.  
> *(※ 본 문서는 실제 웹사이트 코드 변경 전 검토용 기획서입니다.)*

## 1. 개편 핵심 변경 사항 요약

1. **메인 화면 `#skills` 4대 스킬 카드 현실화 (가짜 Direct3D 제거)**:
   - 기존 템플릿의 가짜 문구(`C++ & Direct3D: Win32 API 윈도우 생성, HLSL 셰이더 기초`)를 전면 삭제하고, **준수님이 실제로 구현하고 검증한 100% 실전 엔지니어링 역량**으로 개편.
   - 4대 스킬:
     - **스킬 1**: `C# & Unity Engine (Core)` — 상태 머신(`GameState`), `ScriptableObject` vs 런타임 데이터 분리, `Addressables` 동적 관리
     - **스킬 2**: `Architecture & Control Flow (Clean Code)` — 4계층 매니저 시스템, `UniTask` 비동기 실행 순서 제어, `Action`/`event` 데이터-UI 디커플링
     - **스킬 3**: `Network & Multiplayer (TCP Socket)` — C# .NET 콘솔 TCP 전용 소켓 서버, 헤더 기반 패킷 프레이밍(Framing) 및 직렬화 기초
     - **스킬 4**: `Data Logging & AI Dashboard (Pipeline & SQLD)` — 게임 분석용 핵심 로깅 스키마(행/열) 설계, Output 로그(CSV) 수집 및 AI 연계 대시보드 시각화 파이프라인, SQLD 자격
2. **좌측 상시 고정 프로필 영역**:
   - 좌측 상시 노출 프로필 패널에 **'게임 플레이 이력(Game Experience & Log)'** 바로가기 링크를 추가하여, 플레이어이자 분석가로서의 성실한 게임 경험을 방문자가 언제든 확인할 수 있도록 배치.
3. **기존 2번 과제(`assignment-02`) 2개 독립 과제로 분할**:
   - **과제 2-A**: `50일간의 연속 게임 플레이 일지 및 라이브 경험 기록` (독립 슬롯 분리)
   - **과제 2-B**: `게임 플레이와 모바일 마켓 순위 추이 분석`
4. **전공 수업 과제 6종의 단일 서브 프로젝트 통합 패키징**:
   - 메인 화면의 '그 외 프로젝트' 자리에 분산되어 있던 전공 과제들을 단일 카드 **`[SUB-11] 전공 포트폴리오 수업 과제 컬렉션`**으로 묶음.
   - 해당 상세 페이지 진입 시 **카드 그리드(Card Grid) 뷰**로 6개 과제를 한눈에 열람하도록 구조화하여, 포트폴리오 전문성을 지키면서도 학점 평가 증빙을 완벽히 보존.
5. **[UI/UX 긴급 버그 픽스] 프로젝트 상세 페이지 테이블 홀/짝수 행 hover 인터랙션 정상화**:
   - `assets/css/project-detail.css`에서 `tbody tr:nth-child(even)`의 배경색 우선순위 때문에 짝수 행에서 마우스 hover 시 하이라이트가 씹히거나 먹통이 되는 버그 수정 (`tbody tr:hover, tbody tr:nth-child(even):hover` 일관 적용).
