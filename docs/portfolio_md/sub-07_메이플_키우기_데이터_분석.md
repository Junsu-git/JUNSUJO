# [SUB-07] 메이플 키우기 데이터 분석

2026-10-16 원본 재확인에 맞춰 정정한 웹 공개 원고입니다. 이전 요약 원문은 반영 전 백업에 보존합니다.

## 개요와 담당

3인 팀 토끼와거북이의 SWTestQA 과제입니다. 신규·5n·6n·7n 계정 4개 계층을 대상으로 14일간 플레이 지표를 기록했습니다. 팀장으로 로깅 모델과 비교 기준을 설계하고 분석·발표 자료 제작을 담당했습니다. 기여율 수치는 표기하지 않습니다.

## 관찰과 비교

다음 값은 최종 발표자료의 정리 값입니다. 로깅 시트의 반올림된 평균 표기와 구분합니다.

| 7n 계정 | 1일차 | 14일차 |
|---|---:|---:|
| 레벨 | 73 | 81 |
| 전투력 | 1,292,880,000 | 6,177,450,000 |
| 데미지 | 104,585,202 | 302,512,687 |

전투력 대비 데미지 비율의 변화는 `(말기 데미지 / 말기 전투력) / (초기 데미지 / 초기 전투력) - 1`로 비교합니다. 발표자료는 -39.47%로 표기하며, 사이트는 반올림하여 약 39.5% 감소로 소개합니다. 이전 요약에 적힌 -62%, 6n -2%는 최종 발표자료와 일치하지 않아 사용하지 않습니다. 이는 관측 조건에서의 비교이며 게임 내부 공식이나 이탈의 인과관계를 증명하지 않습니다.

## 수집과 QA

실시간 버프로 수치가 변하는 문제를 발견해 2일차부터 기본 능력치 상세 값 기준으로 수집 방법을 통일했습니다. 내부 서버 로그 대신 게임 화면의 값을 수동으로 기록했습니다. 챕터 반복 이동 시 몬스터 수와 시간당 보상, 다중 디바이스 로그인 시 세션 만료와 중복 보상 차단을 테스트 항목으로 제안했습니다.

## 개선 제안과 한계

무기 획득에 집중된 성장 체감을 누적형 강화로 분산하고, 공격 기여도와 생존 기여도를 구분한 지표를 제안했습니다. 표본과 기간이 제한되며 버프·장비·길드 조건을 완전히 통제하지 못했습니다. 운영사의 수정 여부를 직접 검증한 결과로 표현하지 않습니다.
