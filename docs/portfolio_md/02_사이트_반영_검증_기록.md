# 사이트 반영 및 사실 확인 기록

2026-10-16. 사용자 지정 전체목차와 개편 계획을 기준으로 기존 정적 HTML 사이트를 개편했습니다. 원본 저장소 반영 전 변경 파일의 바이트 백업과 해시를 보관합니다. 커밋·푸시·사이트 배포는 수행하지 않습니다.

## 구현한 구성

- 메인: 프로필·4대 역량·대표 프로젝트 4개·그 외 프로젝트 11개. 미확정 기여율은 생략.
- 상세: 대표 프로젝트 4개와 서브 프로젝트 10개를 근거 문서의 개요·역할·구조·문제 해결·결과물·회고로 교체.
- SUB-11: 과제 6종 카드 그리드. 과제마다 허브 복귀 링크 제공.
- 과제 02-A: 기존 원문에서 작성된 플레이 기록 2건과 예정 48건. 50일 연속 완료로 표현하지 않음.
- 과제 02-B: 기존 순위 데이터베이스와 마켓 분석. 플레이 일지·개인 이력은 별도 페이지로 이동.
- 게임 플레이 이력: 루트 원문 Markdown을 기준으로 별도 페이지 작성, 고정 프로필에서 연결.
- 표 hover: 공통 CSS로 홀수·짝수 행을 동일하게 처리. 기존 테마와 반응형 배치를 유지.

실제 경로는 [페이지 대응표](./site-content-map.json), 링크 확인은 [Drive 확인 기록](./drive-link-checks.json)을 참고합니다.

## 원고에서 정정한 사항

1. **보드게임 룰북·원페이저 링크**: 원고의 2개 ID는 인증된 Drive에서도 NOT_FOUND. 확인된 보드게임 원본 폴더의 실제 PDF ID로 교체했습니다.
2. **메이플 로깅 링크**: 존재하지 않는 예시형 시트 ID 대신 폴더에서 찾은 실제 네이티브 Google Sheets와 최종 발표자료를 연결했습니다.
3. **메이플 효율 수치**: 요약의 -62%와 6n -2%는 최종 발표자료(-39.47%, -18.8%)와 불일치. 공개 페이지는 7n의 최종 발표 정리 값과 약39.5% 감소를 명시했습니다. 로깅 시트와 발표자료의 반올림/정리 값 차이도 구분합니다. 측정한 조건에서의 관찰이며 내부 공식·인과관계의 증명은 아닙니다.
4. **50일 기록**: 기존 HTML에 완료로 작성된 항목은 2건이며 날짜도 연속되지 않습니다. 50일은 목표로 구분했습니다.
5. **에린의 조각들**: 상용 게임에 존재하는 구현 시스템이 아니라 이벤트 기획 제안서입니다. 기존 과제 본문의 배포 수준·예외 처리 완료 단정도 설계 수준으로 수정했습니다.
6. **겨울 이벤트**: 가정 데이터·제약 예산·목표 KPI입니다. 실제 서비스 지표 개선이나 집행 성과로 표현하지 않습니다.
7. **AI 대시보드**: 자동 수집·AI 연동 완료를 확인할 근거가 없어 네 번째 역량을 로깅·분석·SQLD로 표현했습니다. 메이플 수집은 화면 값의 수동 기록입니다.
8. **RootMarket**: 페이지의 구현·테스트 설명은 2026.09 개발 기록 기준으로 명시했습니다. 현재 로컬 프로토콜의 16바이트 헤더와 64KB 제한은 정적으로 확인했으나 게임 런타임·멀티클라이언트 테스트를 새로 수행하지 않았습니다.
9. **기여율**: 팀 프로젝트의 미확정 수치와 겨울 회고에 남은100% 표기를 공개 페이지에서 제거했습니다. 개인 과제의 역할과 게임 규칙상의 확률은 구분합니다.
10. **자료 보존**: 새로운 스크린샷이나 성능 수치를 만들지 않았습니다. 갤러리에는 이미지가 준비되지 않은 상태를 유지합니다.

## 확인 범위와 남은 사항

- Drive 파일 존재와 제목·형식은 로그인된 연결로 확인했습니다. 방문자에게 공개되는 권한은 별도 검증하지 않았으며 공유 설정을 변경하지 않았습니다.
- 프로필 학력·자격·활동·수상 및 프로젝트 역할은 사용자가 지정한 원고와 로컬 기록을 반영했습니다. 성적증명서·자격증·수상 증명서를 새로 인증한 것은 아닙니다.
- 모의 입사 경진대회 세부 수상 일자·등급, 일부 팀 프로젝트 기여율, RootMarket 공개 저장소·시연 링크, 추가 갤러리 이미지는 확정 자료가 없어 보류합니다.
- 원고에 있는 모든 게임 수치·예산·역할을 독립적으로 재현했다는 의미가 아닙니다. 기존 기록·기획 가정·관찰 결과·향후 계획을 구분했습니다.
