# 사이드바 게임 플레이 이력

- 목차 바로 아래에 배치한다. 하단 소셜 링크와 분리해 빈 공간 때문에 버튼이 밀려 내려가지 않도록 한다.
- 기본은 접힌 상태다. 제목을 클릭하거나 키보드 Enter / Space로 펼치고 접는다. 네이티브 `details`를 사용해 JavaScript 없이 동작한다.
- 게임명은 왼쪽, 플레이 시간은 오른쪽에 정렬한다. 긴 게임명은 줄바꿈하고 시간은 한 줄로 유지한다.
- 목록 높이는 최대 260px 또는 화면 높이의 35%로 제한한다. 내부 스크롤과 고정 열 제목을 사용하며, 키보드로도 목록을 스크롤할 수 있다.
- 시간은 `게임 플레이 이력.md` 및 기존 `game-experience.html`의 기록을 따른다. 레벨·진행도를 시간으로 바꾸지 않고, 시간이 없는 게임은 `미기록`으로 표시한다.
- 진행도와 감상은 기존 상세 페이지 링크로 연결한다. 시간 갱신 시 원문, 상세 페이지, `index.html`의 요약 목록을 함께 수정한다.

검증: `node scripts/verify-sidebar-play-history.cjs`로 접기/펼치기, 키보드 스크롤, 위치 유지, 시간 표시, 상세 링크와 화면 너비별 넘침을 확인한다.
