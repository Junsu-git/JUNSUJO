# 취업 활동 대시보드

## 구성

- 진입: `index.html` 사이드바의 포트폴리오 / 취업 활동 전환.
- 독립 주소: `career.html`. 정적 파일 직접 열기와 HTTP 환경 모두 지원.
- 기존 테마 초기화·설정·페이지 목차 스크립트를 재사용한다.
- 숫자 카드, 월별 누적 막대, 활동 유형 도넛, 주요 활동 도식, 타임라인·활동 카드 보기를 제공한다.
- 월·유형·검색 조건은 교집합으로 적용한다. 선택은 URL에 보존하며 뒤로 가기에서 복원한다.
- 상세 패널은 네이티브 dialog다. Escape 닫기·초점 복귀를 지원한다.
- CSV는 현재 선택한 기록을 내보낸다. Excel용 UTF-8 BOM을 포함한다.

## 원장과 집계

기준 문서: `100_Projects/2026-11-19_3학년2학기_취업활동_아카이브/활동원장.md`.

- 기준일 2026-11-19, 활동 묶음 12개, 일정 22건.
- 활동 기록 20건, 접속 화면 기록 1건, 예정 1건.
- 수상 1건, 업무 진행 2건, 발표·멘토 피드백 1건.
- 월별 전체 일정: 8월 1건, 9월 8건, 10월 4건, 11월 9건.
- 3월 아이디어 구상은 프로젝트 배경으로만 표시한다.
- 11/20 일정은 날짜가 지나도 자동 완료로 전환하지 않는다.
- 인터뷰 접속 기록을 시청·학습 성과로 집계하지 않는다.
- 총 참여 시간·숙련도·가산점·임의의 달성률을 만들지 않는다.

현재는 수업용 전체 활동이다. 지원 전형·운전 연수도 사용자 요청에 따라 포함한다. 기업 공개용 별도 데이터 선별·권한 기능은 구현하지 않았다.

## 파일

- `assets/js/career-data.js`: 활동·일정, 집계, 필터, CSV. Node와 브라우저에서 같은 데이터를 사용한다.
- `assets/js/career.js`: 차트·목록·상세·필터·다운로드 동작.
- `assets/css/career.css`: 대시보드 전용 레이아웃·반응형·테마.
- `assets/css/site-mode.css`: 두 페이지의 모드 전환.
- 원장 수정 시 데이터의 날짜·상태·설명을 함께 갱신하고 검증한다.

## 검증

- `node scripts/verify-career-data.cjs`: 원장 수치, 검색, 교집합, 상태 구분, CSV.
- `node scripts/verify-career-browser.cjs`: 실제 페이지 전환, 테마 유지, 그래프 필터, 비어 있는 결과, 초기화, 예정 제외, dialog, 키보드, 증빙 이미지, CSV, 뒤로 가기, 관련 기록 초점.
- 320/390/800/1440px × 라이트/다크 8개 조합. 가로 넘침·중복 ID·본문 10단어 제한 검사.
- `node scripts/verify-content-browser.cjs`: 새 페이지를 포함한 기존 전체 사이트 회귀 검사.

검증 시 `PORTFOLIO_QA_OUTPUT`을 쓰기 가능한 경로로 지정한다. 스크린샷과 JSON 결과를 해당 경로에 저장한다. 브라우저 검증은 현재 환경의 번들 Playwright와 Chrome 경로를 사용한다.
