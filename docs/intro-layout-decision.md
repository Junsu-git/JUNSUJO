# 소개 이력 영역의 레이아웃 결정

## 문제와 원인

1. '학력과 이력'은 공통 상자의 제목이었고 '자격·활동·수상'은 내부 패널의 제목이었다. 서로 다른 중첩 단계와 패딩 때문에 제목 높이가 달랐다.
2. 큰 상자가 연표와 패널을 함께 감싸면서 열 사이와 짧은 패널 아래의 여백까지 하나의 빈 공간처럼 보였다.
3. 펼침 여부에 따라 1열과 2열을 전환하고 버튼을 열 너비에 맞춰 늘렸다. 접을 때 화살표의 위치와 텍스트 줄바꿈이 함께 바뀌었다.

## 선택한 방식

**항상 보이는 독립 카드 두 개를 상단 정렬한다.** 학력과 이력은 왼쪽 카드, 유한대학교의 자격·활동·수상은 오른쪽 카드에 둔다. 좁은 화면에서는 같은 읽기 순서로 한 열에 쌓는다.

| 문제 | 적용 방식 | 이유 |
| --- | --- | --- |
| 제목 높이 불일치 | 두 제목을 같은 깊이의 h3로 배치하고 같은 패딩·크기·행간 사용 | 카드 제목을 같은 기준선에서 읽을 수 있음 |
| 과도한 빈 공간 | 큰 공통 테두리를 제거하고 카드 간격 20px, 자연 높이와 상단 정렬 사용. 날짜 열과 연표 행 간격도 축소 | 짧은 카드에 불필요한 높이를 강제하지 않고 정보 간 거리도 줄임 |
| 접을 때 위치 이동 | 유한대학교 펼침 버튼과 관련 스크립트를 제거하고 정보를 상시 표시 | 관련 정보가 한 학교에만 있는 현재는 접기보다 한눈에 확인하는 편이 유용하며, 상태 전환에 따른 레이아웃 이동도 없어짐 |

두 카드의 높이를 억지로 맞추지는 않는다. 내용량이 다르면 카드 아래에 페이지 배경이 보이는 것은 자연스럽고, 이를 메우기 위해 내용을 늘리거나 큰 빈 프레임을 만들지 않는다.

## 비교한 대안

- 버튼과 열 너비만 고정하고 접기 유지: 화살표 이동은 줄지만 접힌 뒤에도 빈 열이 남는다.
- 모든 정보를 한 열에 배치: 가장 단순하지만 데스크톱에서 관련 이력을 동시에 확인하기 어렵다.
- 독립 카드 상시 표시: 제목 정렬, 빈 공간, 접기 이동을 함께 해결하므로 현재 구성에 선택했다.

## 범위와 확장

- 학교·복무·어학연수의 최신 제공 정보와 활동 목록을 유지한다.
- 학력은 유한대학교 → 사회복무요원 → CHRIST → 서울디지텍고등학교 순서를 유지한다.
- 상세 페이지, 대표 프로젝트 카드, 테마 동작은 변경하지 않는다.
- 다른 기관의 실제 활동 이력이 생기면 해당 기관명을 명시한 추가 카드나 그룹으로 확장한다. 아직 자료가 없는 기관에 빈 버튼·패널을 만들지 않는다.

- 스크린샷으로 라이트·다크·모바일의 카드 간격과 제목 정렬 확인.
