# 상호작용과 모션

## 맨 위로 이동

기존 버튼은 `.skip-link, #main-content, h1` 중 문서에서 먼저 나오는 요소에 포커스를 주었다. 이 때문에 숨겨진 본문 바로가기 링크가 화면에 나타났다.

버튼은 본문에 프로그래밍 포커스를 주고 화면만 최상단으로 이동하도록 수정했다. 본문 바로가기는 `:focus-visible`일 때 표시하며, Tab 키로 접근하고 Enter로 본문에 이동하는 기능을 유지한다. 공통 스크립트를 사용하는 메인·상세 페이지에 적용된다.

## 메인 페이지 모션

- 대표·그 외 프로젝트와 연락처: 호버 시 3px 상승, 테두리·그림자 변화. 문서 배치와 카드 크기는 유지한다.
- 이미지: 이미지 영역 안에서 1.025배 확대한다. 준비 중인 이미지에는 아이콘의 작은 이동으로 반응을 준다.
- 링크·버튼: 방향 화살표 이동, 눌림 반응과 색상 전환을 사용한다.
- 목차: 작은 수평 이동과 배경 전환을 적용한다.
- 학력·활동·보유 기술: 정보 카드의 위치는 고정하고 테두리·배경으로 반응한다. 타임라인에는 노드 주변 강조를 추가한다.
- 전환 시간은 기본 220ms, 이미지 280ms다. 반복 애니메이션이나 콘텐츠를 숨기는 진입 효과는 사용하지 않는다.
- 이동·확대 효과는 마우스처럼 정밀 포인터가 있고 호버 가능한 환경에만 적용한다. 키보드 포커스에는 테두리 강조를 유지한다.
- `prefers-reduced-motion: reduce`이면 전환과 카드·이미지·화살표의 이동을 없애고 즉시 상태만 표시한다.

검증: `node scripts/verify-navigation-motion.cjs`.
