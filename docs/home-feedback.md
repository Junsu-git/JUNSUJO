# 메인 페이지 피드백 반영

- 프로필은 이름 한 번과 '게임 클라이언트 개발자', Unity · C#으로 정리했다.
- 소개에 학력과 복무 카드를 통합하고, 보유 기술 → 대표 프로젝트 4개 → 그 외 프로젝트 5개 → 연락처 순서로 배치했다.
- 현재 5개 과제는 그 외 프로젝트 아래 연속된 가로 카드로 유지했다. 추가 전공 포트폴리오 작업은 자료를 받을 때 같은 컴포넌트로 추가할 수 있다.
- 메인 전용 home.css에서 라이트의 선명한 파란 강조와 다크의 짙은 파란 선택 배경을 복원했다. 메인 제목·링크·기술 태그·목차 선택에 적용한다.
- 연락처는 이메일·GitHub의 동일한 카드 두 개로 구성했다.
- 소개의 중복 프로젝트 이동 버튼을 제거했다.
- home.js는 메인 목차만 처리한다. 소개/기술/프로젝트와 페이지 끝의 연락처 선택 상태를 실제 스크롤에 맞춘다.

검증: verify-home-feedback.cjs에서 순서·프로필·카드 수·목차 선택과 4개 화면 폭 × 2개 테마를 검사했다. qa-portfolio.cjs의 기존 80개 화면 조합·실제 글자 대비 검사도 통과했다.

이번 작업은 index.html과 새 메인 전용 home.css / home.js에 적용했다. 상세 9페이지와 공통 portfolio-system.css / portfolio-system.js는 수정하지 않았다. 별도 리뷰에서도 두 화면 폭에서 다섯 목차의 부드러운 이동과 활성 표시를 확인했다.
