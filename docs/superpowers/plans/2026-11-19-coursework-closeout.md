# Coursework closeout implementation plan

**Goal:** 기존 수업 과제 3건을 정해진 범위의 최종 문서로 마감한다.

**Architecture:** 기존 정적 HTML·공통 CSS를 유지한다. Markdown 원본에서 보고서를 렌더링하고 컬렉션의 명칭과 소개를 동기화한다.

**Tech stack:** Markdown, HTML, 기존 Node·Playwright 검증.

**Spec:** 2026-11-19 사용자 요청: 게임 진행도 중심 회고, 약 1시간 분량, 자바 후반 단원 작성, 소드 x 스태프 심층분석 없이 종결.

## Constraints and rulings

- 기록 정리 범위는 2026-09-17~11-19, 양끝 포함 64일이다. 사용자 정정: 1~50일차는 기존 모바일인덱스 1~50위 게임에 각각 대응한다. 기존 목록·순서를 그대로 유지한다.
- 기존 게임 레벨·랭크·누적 시간과 원래 관찰 날짜를 유지한다. 새 레벨·과거 실측 시간을 발명하지 않는다.
- 약 1시간은 회고·복습의 편집 단위로 표시한다. 기존 30분·40분·2시간 기록을 1시간으로 덮어쓰지 않는다.
- 자바는 기존 1~8단원 기록을 보존하고 9~14단원의 노트·예제·예상 결과를 완성한다. 실행 환경이 확보되면 별도 실제 실행 근거를 남긴다.
- 완료는 과제 문서의 범위 확정·작성 완료를 뜻한다. 개인의 과거 수행 증명이 아니다.

## Tasks

- [x] 1. 자바 단원 9~14 노트 및 통합 예제 작성, 원문·HTML 동기화.
- [x] 2. 기존 모바일인덱스 목록의 1~50위 게임에 대해 50개 분석 기록 작성. 순위·게임명을 보존하고 실제 진도와 가정 예시를 구분하며 기존 계획 목록을 보관.
- [x] 3. 소드 x 스태프 30분 체험 분석으로 마감, 컬렉션 문구·관련 링크·검증 기준 갱신.
- [x] 4. 구조 검사, 예제 검증 가능 여부 확인, 브라우저 100개 화면 조합과 콘텐츠 일치 확인.

## Review focus

회고 순번과 플레이 날짜 혼동, 권장 분량과 실측 시간 혼동, 원문 레벨 보존, 학습노트와 과거 수행 이력 구분, 소드 x 스태프의 후속 진행 표시 제거를 확인한다.

## Verification ledger

- TOP50 이름·순서 50개 원문 일치. 기존 자료 연결 8개, 가정 예시 42개. 빈 계획 카드 제거.
- 브라우저 25페이지 × 2개 너비 × 2개 테마 = 100개 조합: 실패·페이지 오류 0건.
- 별도 읽기 전용 리뷰에서 범위 구분·Java 예제 정적 일관성·로컬 링크를 확인했다. 범위 기호가 취소선으로 렌더링되던 문제를 수정하고 재검증했다.
- JDK 실행 파일이 없어 Java 컴파일·실행은 수행하지 않았다. 예제는 예상 결과로 표시하며 문서 완료 범위와 분리했다.
