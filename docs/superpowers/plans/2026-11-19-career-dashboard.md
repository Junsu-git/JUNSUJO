# Career dashboard implementation plan

**Goal:** 수업용 정량 취업 활동 대시보드를 기존 포트폴리오에 연결한다.

**Approved direction:** 사용자 요청대로 웹으로 구현한다. 기존 테마·내비게이션을 이어 쓰며, 글보다 수치·그래프·도식을 우선한다. 각 문장은 10단어 이하로 작성한다.

**Architecture:** 독립 URL `career.html`, 공통 모드 전환 링크, 공통 테마 스크립트. 신규 전용 CSS·데이터·JS로 기존 페이지 변경을 제한한다. 정적 파일을 직접 열어도 동작한다.

**Data contract:** 2026-11-19 활동 원장의 12개 묶음·22개 일정을 보존한다. 11/20은 예정, 인터뷰는 접속 기록이다. 3월 구상은 학기 집계에서 제외한다. 수상 1건과 업무 진행 2건은 해당 일정만 집계한다. 임의의 점수·전체 시간·가짜 학습 성과를 만들지 않는다.

## Tasks

- [x] 원장 기준 데이터와 집계·필터 동작 검증 작성.
- [x] 독립 페이지·모드 전환·시각화·상세 패널 구현.
- [x] 검색·월·유형 필터와 CSV 다운로드 구현.
- [x] 반응형·테마·접근성·짧은 문장 검증.
- [x] 기존 페이지 회귀 검사, 시각 확인, 읽기 전용 리뷰.

## Review focus

예정·접속 포함 숫자의 의미, 필터 교집합·초기화, 키보드 상세 열기·닫기, 색 이외 그래프 식별, 화면 넘침, 모드 전환 뒤 테마 유지.

## Publication

기존 체크아웃의 정적 사이트를 수정한다. 연결된 Sites 배포 설정은 없다. 이 작업에서 별도 호스팅 프로젝트·도메인·원격 저장소를 생성하지 않는다.

## Verification ledger

- 집계·필터 테스트를 먼저 작성해 실패를 확인한 뒤 구현했다.
- 읽기 전용 리뷰의 history 복원·관련 기록 초점 문제를 각각 재현하고 수정했다.
- 신규 브라우저 흐름과 8개 화면 조합 통과. 작업 폴더 27페이지·108개 조합, 별도 커밋 스냅샷 26페이지·104개 조합 모두 통과.
- 원장과 상태 구분을 보존했다. 본문 텍스트 노드의 10단어 제한을 확인했다.
- 1440px 라이트·390px 다크 스크린샷을 시각 확인했다.
